# IntoTheSpireverse
STS 2 Pre-workshop project

# Build Instructions
Download https://spine-godot.s3.eu-central-1.amazonaws.com/4.2/4.5.1-stable/spine-godot-extension-4.2-4.5.1-stable.zip.
Add the bin folder from the zip into your project.

Spireverse compiles against Art Roller (https://github.com/mikemayhemdev/ArtRoller) through its NuGet package, which restores on build. To run Spireverse, install the Art Roller mod.
